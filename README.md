One original roast line for the Roast the Smart Fridge bounty: a single
sentence that fits in 160 characters and lands its punchline at the end.

> My smart fridge needed a firmware update before it would open, so I stood there hungry while it downloaded a better version of itself.

## Why this line

- **Setup, then sting.** The first half puts you in front of a locked fridge,
  hungry; the last words flip it — the fridge is busy improving *itself*
  while you wait.
- **A real behaviour, pushed one step further.** Smart fridges really do
  download firmware updates; here the update comes before the door opens.
- **Fresh angle.** No milk, no auto-ordering, no 3 a.m. texts — the joke is
  about the appliance's self-improvement, not its shopping list.
- **Economy.** 134 characters, one sentence, nothing to trim, easy to repeat
  to someone else.

## Run it

```sh
python3 main.py            # writes entry.txt, prints the line to stdout
python3 main.py --check    # validates the line against the gate only
```

Writes the line (134 characters, no trailing newline) to
`<MAKEFUN_OUTPUT_DIR>/entry.txt` (default `/output/entry.txt`).
Standard library only, deterministic, no network. The program validates
the gate before writing: UTF-8, 1–160 characters, a single line, not only
whitespace.

See [CANDIDATES.md](CANDIDATES.md) for the ten lines considered and why
this one was picked.
